# Flora UI V2 - актуальные экраны и требования

Браузерные HTML-экраны показывают дизайн, но не выполняют настоящие операции 3ds Max, Merge/Proxy и SQLite. «Утверждено» означает согласованное требование; не гарантирует, что конкретный HTML-макет или установленный плагин уже обновлён.

| Экран | Актуальное поведение / статус |
|---|---|
| Explorer | Поиск, сортировка, папки, Grid/Table, Tile Size, выбор, Favorites/Basket |
| Filters | Утверждённые зависимые пары: группа/категория растения, тип/категория среды; цветение; высота От/До disabled |
| Filters responsiveness | Компактные 4/2/1 колонки по ширине Explorer; ограниченная максимальная ширина; отдельная прокрутка по высоте |
| Properties | Утверждено убрать внутреннюю шапку и настройки порядка/видимости; сразу «Названия», «Ботанические сведения» |
| Grid cards | Утверждены имя модели и две необязательные строки name_ru/name_en, убрать Vol |
| Table View | Утверждены только актуальные ботанические столбцы RU/EN/Latin, цветение, группы/категории/среды |
| Search | Утверждён поиск по имени файла, RU/EN/Latin и названиям похожих растений из similar_json |
| Favorites | Избранное и пользовательские коллекции, сохраняются при очистке импортированных данных |
| Basket | Сбор моделей, чекбоксы, импорт через существующий пайплайн плагина |
| Catalogs | Тематический FloraCOL; устаревший ботанический FloraCat исключить |
| Settings | Утверждена кнопка очистки импортированных данных с подтверждением, без удаления Favorites, исходных .max/.cgeo/превью и сцены |
| Model Analyzer | Целевой список исходных .max и относительных путей, без открытия сцен или измерений |
| Material Manager | Существующий функционал без новых изменений |
