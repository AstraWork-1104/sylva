# Flora UI V2 - экраны и состояние демонстрации

## Актуальный контекст рабочего плагина Flora - 26.10.2026

Это описание десктопной Flora на Python/PySide6, а не утверждение о наличии перечисленных функций в HTML/JS этой ветки. Браузерная карта UI_MAP.md продолжает описывать только фактически существующий веб-код.

В Settings → Library → Library Paths подключаются несколько корневых библиотек .max, объединённых в один индекс моделей. Постоянная вкладка Explorer отображает все библиотеки. По правой кнопке на любой папке FOLDERS доступно Open in New Tab: дополнительная вкладка располагается непосредственно после существующих папочных вкладок и фильтрует общий индекс по полному нормализованному пути папки и её подпапок, без повторного обхода диска, копирования моделей или отдельного индекса.

Папочные вкладки располагаются слева от Catalogs, Scene, Favorites, Basket; при повторном открытии того же пути активируется существующая вкладка. Каждая вкладка хранит свои выбранную папку, поиск, фильтры и прокрутку; открытые вкладки восстанавливаются после перезапуска. Дерево дополнительной вкладки не повторяет её собственный корень, но модели непосредственно в нём доступны; вложенность дочерних папок выражается отступами при одинаковом размере шрифта. Закрывающие крестики компактные, отдельная кнопка добавления вкладки не используется.

Library Paths оформляется с отчётливым выделением строки, колонками Name / Root path и читаемыми длинными путями. Диалоги Add Folder и Edit Library в палитре Flora содержат Name, Root path, обзор папки и Cancel / Save. Diagnostics предоставляет Open log и Copy log. Подробные функциональные решения содержатся в основном документе Flora в Google Docs; изменение этих пояснений не изменяет HTML-макет.

Далее указаны возможности **существующего HTML-макета**. После 1.0.0.44 пользователь отдельно утверждал изменения рабочего Qt: вертикальный Edit Properties, единые dropdown, динамические кнопки, Basket/Filters/Explorer (§20), затем новый цикл с окончательной нижней панелью, англоязычными служебными ярлыками и новым контекстным меню (§21). Часть Qt-тасков ещё НЕ подтверждена выполнением. Сами эти требования НЕ являются подтверждением изменений HTML; код веб-макета не обновлялся. [Основное описание Flora, §§20-21](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit).


**Приоритет для текущего PySide6 (22.10.2026):** пользователь утвердил новый цикл. В первом таске: центрирование/уплотнение навигации, английский Filters, defaults Fonts 16/16/16/15/13/16/17 px + Scale 113%, кнопка скрытия FOLDERS слева от поиска, английская левая колонка Properties с заголовками `Names / Information / Description`, служебные метки Filters английские, реальные категории русские. На скриншоте окно `Flora 1.0.0.46`; commit неизвестен. Последним вторым таском согласованы: нижний бар строго в одну строку - selected слева, три компактных переключателя справа (`USE MATERIAL Scene/Model`, `USE INSTANCES ON/OFF`, `IMPORT MODE Geometry/Proxy`) без Drag подсказки и ready; отсутствие маленьких подзаголовков Scene/All Favorites; Filters Regular/400; прямые пункты Import as Geometry/Proxy и контекстное меню из четырёх закруглённых блоков; Select Model Disabled, если нет узла FloraSource. Результат второго таска **не подтверждён**. [Актуальный контракт, §21](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit). ## Актуализация компоновки и управления (20.10.2026)

- Tile Size теперь открывается одной кнопкой в активном разделе. Ползунок расположен в общем всплывающем окне, а крайнее положение переводит Grid в Table View. Отдельные постоянно видимые ползунки и дублирующие кнопки вида убраны. При переходе в Basket показывается контекстная кнопка, использующая тот же единственный ползунок и сохранённое значение.
- На карточках действия Favorites и Basket размещены друг под другом справа от названий. Кнопки «+» поверх превью нет. На её бывшем месте показывается пассивная зелёная точка только для моделей, присутствующих в демонстрационной Scene; при отсутствии модели точка не отображается.
- Catalogs, Scene, Favorites, Basket имеют единый набор контурных SVG-иконок с подписями справа от каждой иконки, сохраняя порядок и доступность.
- Выравнивание надписей, шрифты, межстрочные интервалы и внутренние отступы унифицированы. Увеличен зазор от строки поиска и инструментов до области результатов.
- Превью Scene и её зелёный индикатор основаны на условных данных браузера и не подтверждают состояние настоящей сцены 3ds Max.

## Компактный Explorer и демобиблиотека (20.10.2026)
- В дереве 8 пунктов: All Plants, Canopy Trees, Evergreen Conifers, Garden Shrubs, Flowering Beds, Perennial Border, Ornamental Grasses, Climbing Plants. Выбор папки действительно фильтрует модели.
- 36 демомоделей: 12 видов по 3 варианта с нейтральными названиями файлов. В основной библиотеке и вспомогательных окнах больше нет названий производителей и томов.
- 9 моделей отмечены зелёной точкой присутствия в условной Scene, остальные не имеют индикатора. Это только имитация, без сканирования 3ds Max.
- Навигация уменьшена до 36 px (на узком экране - до 34 px), подписи теперь размещены справа от иконок.
- Путь под Explorer убран, поиск поднят. Отступ от строки поиска до Grid сокращён примерно вдвое. Иные функции UI сохранены.

### Компактная навигация (20.10.2026)
Все четыре кнопки Catalogs, Scene, Favorites и Basket имеют горизонтальную компоновку: контурная иконка слева, подпись справа. Общая высота панели 36 px, на узких экранах 34 px. Активная вкладка, меню Catalogs и счётчик Basket сохранены.
