# Flora V2 - состав экранов и статусы

Все новые функции - демонстрация HTML, а не работающий код 3ds Max.

| Экран | Демонстрируемое поведение |
|---|---|
| Explorer | Сохранены папки, поиск, Grid/List, выделение, свойства, Import Descriptions |
| Favorites | Независимые отметки и коллекции |
| Basket | Существующий набор растений, чекбоксы, удаление, Clear Basket и Import Preview |
| Catalogs | Выпадающее меню, скролл, подсветка выбранного каталога и Add Catalog |
| City | Courtyards, Streets & Boulevards, Lawn Areas, Parks & Squares с вложенными сочетаниями |
| Forest | Coniferous Forest, Deciduous Forest, Forest Edge, Forest Clearing и другие композиции |
| Подборка | Название, назначение, описание, группы моделей по ролям, Grid/List |
| Properties / Model | Basic Information, Visual Characteristics, Geometry & Technical |
| Properties / Composition | Название, назначение, описание, число моделей, группы растений |
| Customize Properties | Чекбоксы полей, изменение порядка кнопками и перетаскиванием, Show All, Reset to Default |
| Properties / Similar Plants | Компактный блок с превью и переходом к модели |
| Properties / Resize | Изменение ширины перетаскиванием границы или стрелками клавиатуры |
| Filters | Тип, листва, цветение, минимальная высота, множественные категории озеленения |
| Dynamic Categories | 30 исходных категорий и кнопка демонстрации новой категории |
| Model Analyzer | Отдельное окно из Settings / Library, дерево папок, чекбоксы |
| Analyzer Warning | Save / Don't Save / Cancel, предупреждение о сбросе сцены в реальном плагине |
| Analyzer Scanning | Прогресс, файл, счётчики, журнал, таблица результата |
| Analyzer Export | Скачивание демонстрационного CSV |
| Import Descriptions | Независимое подключение имён файлов описаний, без чтения SQLite |
| Material Manager | Старое окно Relink, Textures, Materials, без изменений |

В HTML нельзя реально изменять сцену, сохранять её, анализировать исходные .max, читать SQLite, создавать Proxy или автоматически размещать композиции. Данные каталога, геометрии и ботаники - иллюстративные. Scatter отсутствует.

Версия для проверки - flora-ui-v2, исходная утверждённая версия - flora-ui.
