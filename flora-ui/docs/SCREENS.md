# Flora UI - экраны и статус

| Экран | Функции в браузерном макете | Статус настоящего плагина |
|---|---|---|
| Catalog / Explorer | 72 примера растений, дерево MaxTree, Grid/List, поиск, сортировка, выделение, карточки и свойства | Каталог и просмотр входят в рабочую основу |
| Catalog / Favorites | Звёздочки, локальное сохранение отметок в браузере, коллекции | Favorites входит в рабочую основу |
| Catalog / Landscape (пример установленного каталога) | Тематические категории, фильтрация, Add Catalog | Каталоги `.floracat` - утверждённая модель, Landscape не встроенный обязательный каталог |
| Catalog / Import Basket | Добавление иконкой, правым кликом и Shift + правым кликом, локальное хранение выбранных моделей, чекбоксы, удаление, Clear Basket, регулировка размера карточек, Import Preview | Спецификация согласована, реализация в плагине не подтверждена; сцена в HTML не изменяется |
| Explorer / Import Plant Data | Выбор нескольких информационных `.floracat`, локальное сохранение списка имён без чтения SQLite | Будущая отдельная функция, не создаёт тематические вкладки и не заменяет Add Catalog |
| Proxy footer | Geometry / Point Cloud | Управление новыми Corona Proxy предусмотрено действующей архитектурой |
| Settings / Materials | Use Scene Materials (default ON), пояснение режимов MaxScript | Согласованное изменение, не подтверждено как готовое |
| Material Manager / Relink | Корни поиска, таблица, статусы, предварительный результат | Согласованный будущий инструмент |
| Material Manager / Textures | Сводка групп дубликатов и выбор карт | Согласованный будущий инструмент |
| Material Manager / Materials | Сравнение CoronaPhysicalMtl / CoronaLegacyMtl | Подлежит проверке реализуемости |

## Ограничения демо

Прототип работает в браузере. Данные о растениях, путях к текстурам, состояниях Relink и статистика очистки - демонстрационные. Макет не подключён к 3ds Max, Corona и локальному файловому индексу.

Никакая кнопка «Run», «Apply», «Update», «Refresh», «Import» или «Add Catalog» внутри браузерного макета не утверждает, что изменила реальную сцену. Операции показывают уведомление или изменяют только браузерное представление.

Basket Import в HTML только показывает ожидаемый сценарий (один слой Flora Import, нулевая точка, исходные имена, общие настройки, проверка совпадений имен объектов); корзина не очищается от просмотра, так как успешного импорта в 3ds Max не было.

Полный `.floracat` - SQLite 3 с категориями и метаданными; отдельный редактор файлов в интерфейс не включён.

## Навигация

Основная точка входа - \`index.html\`. Иконка слоёв между Refresh и Settings открывает \`material-manager.html\` как отдельное окно браузера. Если браузер блокирует новое окно, можно открыть файл менеджера напрямую.

В будущих итерациях все экраны дорабатываются в одном общем проекте, без отдельных несвязанных HTML-тестов.
