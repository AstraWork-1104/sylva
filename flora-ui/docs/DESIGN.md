# Flora UI V2 - правила дизайна

Ветка flora-ui-v2 содержит отдельный концепт; исходный утверждённый макет в flora-ui сохранён.

## Визуальная система

Темный лесной зелёный, основы #111c15, #17241b, #1c2d21; акцент #315d3a, #a6db7e; тонкие контуры #2f4b37; скругления 5-9 px. Компактная типографика. Плоские кнопки без рельефного глянца. Сохраняются карточки, Grid/List, Explorer, Favorites, Basket и нижняя панель Corona Proxy.

## Иерархия

Первая строка: Explorer, Favorites, Basket, Catalogs. Выпадающее меню Catalogs: произвольные тематические каталоги, выбранный пункт и Add Catalog внизу. Не плодить отдельные вкладки.

Слева - папки или дерево «каталог / тип пространства / композиция». В центре - модели, сгруппированные по ролям (Trees, Shrubs & Low Conifers, Perennials & Groundcovers). Справа - Properties с настраиваемой шириной.

## Properties

Одна панель Property / Value со сворачиваемыми Basic Information, Visual Characteristics и Geometry & Technical. Пользователь включает и выключает поля, меняет порядок, сбрасывает настройки. Настройки сохраняются в браузере. Похожие растения - мини-список с превью. Внутри подборки без выбора модели показываются свойства композиции.

## Фильтры

Компактный экран с категориями Decorative & Designed Planting (20) и Natural & Wild Vegetation (10), множественным выбором и поиском. Категории динамические и не являются самостоятельными вкладками.

## Model Analyzer

Отдельное компактное окно, чекбоксы папок, Start, обязательное предупреждение Save / Don't Save / Cancel, процесс, счётчики, результат и CSV. Демонстрация не может сохранять или сбрасывать сцену 3ds Max.

## Разделение данных

Import Descriptions в Explorer добавляет описания видов, отдельно от Catalogs → Add Catalog для тематических сочетаний. Геометрические параметры относятся к конкретной модели, ботанические сведения - к виду. В прототипе все значения и подборки примеры, без реального чтения .floracat.

Не возвращать Scatter или инструменты автоматического размещения. При изменении HTML/CSS/JS пересобрать автономный Flora-UI.html со встроенными Material Manager и Model Analyzer.
