# Flora UI V2 - дизайн веб-макета

Актуализировано 20.10.2026. Ветка `flora-ui-v2`, папка `flora-ui/`. Описывается **фактическое состояние веб-прототипа на 20.10.2026**, не установленный плагин. Позже для PySide6 отдельно утверждены новая полноширинная Edit-форма Properties, несворачиваемые секционные заголовки, единые popup-списки, адаптивные кнопки и компактные Basket/Explorer/Filters ([основное описание, §20](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit)). Они **не внесены в веб-код** этим обновлением документации.


## Отличия от последнего согласованного Qt UI (22.10.2026)

В новом цикле утверждены: верхние вкладки строго центрированы по высоте и чуть ближе друг к другу; кнопка Filters на английском, текст Regular/400; новый набор defaults шрифтов и масштаб 113%, без удаления настроек Fonts; зеркальная кнопка сворачивания FOLDERS слева от поиска; английские заголовки Properties `Names / Information / Description` и названия полей только одним словом; английские служебные подписи Filters при исходных русских категориях. Последняя компоновка нижнего бара - **одна строка**: selected слева, справа подряд `USE MATERIAL [Scene | Model]`, `USE INSTANCES [ON | OFF]`, `IMPORT MODE [Geometry | Proxy]`, без Ready/Drag подсказок и большого горизонтального распределения.

Контекстное меню плитки в PySide6: `Import as Geometry / Import as Proxy`, затем `Select Model` (Disabled без соответствующего узла FloraSource), затем `Add to Basket / Add to Collection`, затем `Properties / Open in Windows Explorer`; блоки разделены тонкими линиями, оболочка и hover/подменю скруглены и выдержаны в зелёной палитре. В Scene/Favorites убрать мелкие повторяющиеся строки под заголовками. Указанные изменения принадлежат **последнему выданному корректирующему таску** и **не подтверждены выполнением**. Точный текст - [спецификация Flora, §21](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit). Фактический веб-код данным изменением документации не затронут.

## Визуальная система
Плоская тёмно-зелёная палитра: `#111c15`, `#17241b`, `#1b3023`, `#203628`; границы `#2f4b37`/`#3a5b41`; текст `#e3eee0`; акцент `#a6db7e`. Общая внешняя рамка Grid без дополнительных постоянных контуров карточек. Filters занимает доступную ширину центральной области; фон совпадает с невиделенной карточкой, компоновка 4/2/1 зависит от ширины панели.

Навигация: один текстовый Explorer слева; справа Catalogs → Scene → Favorites → Basket, все четыре с иконкой СЛЕВА от видимой текстовой подписи. Tooltip/aria-label и активность обязательны. Шапка Flora/Library/Refresh/Settings сохраняется. Basket имеет отдельную область с чекбоксами Include.

## Реализованные состояния
Grid показывает исходное имя файла и при наличии RU/EN, без Vol. Table содержит девять утверждённых столбцов и выводит несколько сред. Сохраняются сортировка, изменение ширины/порядка колонок, мультивыделение, общий Tile Size и поиск. Filters: группа/категория, тип/категория среды, цветение, disabled высота, сброс, условия AND.

Scene: встроенный набор условных записей FloraSource, группировка по нормализованному пути без разделения Geometry/Proxy, счётчики ×N, заглушка отсутствующего исходного файла, обновление по Refresh и контекстная команда Select Model. Отсутствует связь с фактической сценой 3ds Max.

Properties: раскрываемые фиксированные секции «Названия» и «Ботанические сведения», без внутренней шапки и конфигуратора полей. Карандаш открывает поля, галочка сохраняет, крестик отменяет. Имя .max неизменно. Встроенная валидация категорий, хранение демонстрационных ручных overrides в localStorage по нормализованному пути исходника, приоритет сохранённого пустого значения, обновление Grid/Table/Search/Filters. Для смены выбранной модели/основной вкладки при несохранённых правках - Save/Discard/Stay.

Import Mode общий для Explorer и Basket: Geometry / Proxy; выбор локально запоминается. Settings отображает Use Instances (OFF), Point Cloud, Proxy Cache с подтверждаемой опасной очисткой и Uninstall с отдельным подтверждением. Браузерные диалоги никогда не выполняют эти действия. Model Analyzer и Material Manager остаются отдельными демо-окнами, автономный HTML содержит их встроенные копии.

## Разграничение статусов
Встроенный Scene - не настоящие User Properties из 3ds Max. localStorage - не `properties_overrides.sqlite` и не INI. Реальный Merge, Corona Proxy Cache, Point Cloud API, Instance и Uninstall в браузере недоступны. Для реализации и host-проверки пользоваться [основной спецификацией](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit).

## Актуализация компоновки и управления (20.10.2026)

- Tile Size теперь открывается одной кнопкой в активном разделе. Ползунок расположен в общем всплывающем окне, а крайнее положение переводит Grid в Table View. Отдельные постоянно видимые ползунки и дублирующие кнопки вида убраны. При переходе в Basket показывается контекстная кнопка, использующая тот же единственный ползунок и сохранённое значение.
- На карточках действия Favorites и Basket размещены друг под другом справа от названий. Кнопки «+» поверх превью нет. На её бывшем месте показывается пассивная зелёная точка только для моделей, присутствующих в демонстрационной Scene; при отсутствии модели точка не отображается.
- Catalogs, Scene, Favorites, Basket имеют единый набор контурных SVG-иконок с подписями справа от каждой иконки, сохраняя порядок и доступность.
- Выравнивание надписей, шрифты, межстрочные интервалы и внутренние отступы унифицированы. Увеличен зазор от строки поиска и инструментов до области результатов.
- Превью Scene и её зелёный индикатор основаны на условных данных браузера и не подтверждают состояние настоящей сцены 3ds Max.

## Компактный Explorer и демобиблиотека (20.10.2026)
- В дереве 8 пунктов: All Plants, Canopy Trees, Evergreen Conifers, Garden Shrubs, Flowering Beds, Perennial Border, Ornamental Grasses, Climbing Plants. Выбор папки действительно фильтрует модели.
- 36 демомоделей: 12 видов по 3 варианта с нейтральными названиями файлов. В основной библиотеке и вспомогательных окнах больше нет названий производителей и томов.
- 9 моделей отмечены зелёной точкой присутствия в условной Scene, остальные не имеют индикатора. Это только имитация, без сканирования 3ds Max.
- Навигация уменьшена до 36 px (на узком экране - до 34 px), подписи теперь размещены справа от иконок.
- Путь под Explorer убран, поиск поднят. Отступ от строки поиска до Grid сокращён примерно вдвое. Иные функции UI сохранены.

### Компактная навигация (20.10.2026)
Все четыре кнопки Catalogs, Scene, Favorites и Basket имеют горизонтальную компоновку: контурная иконка слева, подпись справа. Общая высота панели 36 px, на узких экранах 34 px. Активная вкладка, меню Catalogs и счётчик Basket сохранены.
