# Flora UI V2 - фактический дизайн HTML

Ветка `flora-ui-v2`. Основной контракт: [Flora](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit). Этот документ фиксирует **реализованный браузерный макет**, не установленный плагин.

## Визуальная система и компоновка
Плоский тёмно-зелёный UI: поверхности `#111c15`, `#17241b`, `#1c2d21`, `#203628`; ввод `#193226`, контуры `#2f4b37`/`#3a5b41`, текст `#e3eee0`/`#91aa95`, акцент `#a6db7e`. Компактные отступы и границы. Вкладки Explorer/Favorites/Basket/Catalogs; папки слева, результаты и Filters в центре, управляемая Properties справа, Proxy снизу.

Общий Tile Size хранится локально и действует на Explorer, Favorites, Basket, демонстрационные FloraAtlas/FloraCOL. Небольшие коллекции оставляют свободное место справа, полные ряды растягиваются на рабочую область. Последняя позиция = Table View. Перестройка выполняется без повторной загрузки изображений.

## Filters
Группа растения -> категория: Деревья - Лиственные, Хвойные, Пальмы; Кусты - Лиственные, Хвойные, Папоротники, Злаки, Вьющиеся, Многолетники, Суккуленты; Трава - Травы, Цветы, Почвопокровные, Луковичные.
Тип среды -> категория: Природные - Лесная, Луговая, Водная, Прибрежная, Степная, Пустынная, Горная; Домашние - Улицы, Парки, Сады, Дворы, Интерьеры. Зависимые категории disabled до выбора родителя и сбрасываются при изменении. «Все категории» конкретной среды требует непустого массива. Цветение Все/Да/Нет, высота От/До disabled. Независимые условия AND. Вёрстка 4/2/1 по ширине центральной области, max ~860 px, своя вертикальная прокрутка при фиксированном заголовке.

## Grid, Table, Properties, Search
Grid показывает filename и только существующие RU/EN, без Vol. Table: девять полей - модель, RU, EN, Latin, цветение, группа и категория растения, тип и категория среды. Для нескольких сред значения перечисляются, действия Favorites/Basket находятся внутри первой ячейки. Сортировка кликом, порядок drag-and-drop, изменение ширины границей; сохраняется локально.

Properties: фиксированные группы «Названия» и «Ботанические сведения», без внутреннего заголовка, шестерёнки или настройки порядка. Все поля постоянны. При мультивыделении несовпадающие значения пусты, similar_json имитируется обычным текстом. Search ищет подстроки без учёта регистра по filename/RU/EN/Latin и именам похожих растений.

## Settings и границы
Settings содержит Library, Import FloraAtlas/FloraCOL, Export JSON, упрощённый Model Analyzer, Fonts collapsed и подтверждаемую очистку. Демонстрационная очистка сбрасывает тестовые метаданные и добавленные тематические демо-каталоги без изменения Favorites, пользовательских коллекций, Basket и UI-настроек. Реальные SQLite, исходные файлы, сцена 3ds Max, Corona Proxy/Merge браузеру недоступны. Истинные статусы PySide6-плагина необходимо проверять отдельно.
