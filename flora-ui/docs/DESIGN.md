# Flora UI V2 - утверждённые правила дизайна

Актуальная ветка: `flora-ui-v2`. Браузерный UI - визуальный референс для реализации в PySide6.

## Визуальная система

Основные поверхности: #111c15, #17241b, #1c2d21, #203628; поле ввода #193226. Акцентные цвета: #315d3a, #a6db7e. Контур: #2f4b37, #3a5b41. Основной текст #e3eee0, вспомогательный #91aa95. Плоские кнопки без глянца и рельефа, тонкие границы, умеренные скругления, компактные отступы.

## Компоновка

Верхние вкладки Explorer, Favorites, Basket, Catalogs. Слева Folders, в центре поиск/сортировка/Tile Size/Filters и Grid/Table, справа открываемая Properties, снизу Corona Proxy. Количество карточек реагирует на ширину окна; масштаб общим Tile Size. При отсутствии названий не создавать пустые строки.

## Filters (утверждены в браузерном макете)

Четыре логических блока: группа/категория растения, тип/категория среды, цветение, высота. Зависимые одиночные списки; дочерний недоступен до выбора конкретного родителя, обновляется и сбрасывается при смене родителя. Точные наборы:
- Группы: Деревья = Лиственные, Хвойные, Пальмы; Кусты = Лиственные, Хвойные, Папоротники, Злаки, Вьющиеся, Многолетники, Суккуленты; Трава = Травы, Цветы, Почвопокровные, Луковичные.
- Природные = Лесная, Луговая, Водная, Прибрежная, Степная, Пустынная, Горная.
- Домашние = Улицы, Парки, Сады, Дворы, Интерьеры.
- Цветение Все/Да/Нет; Высота, см с неактивными От/До.

Широкая панель: компактные элементы максимум примерно 820-860 px, прижатые к левому краю; по фактической ширине Explorer автоматические 4/2/1 колонки. При уменьшении высоты внутренний вертикальный скроллбар Filters, заголовок и «Сбросить» остаются видны. Модели прокручиваются отдельно.

## Properties (последняя согласованная правка, может отсутствовать в текущем HTML)

Убрать всю внутреннюю шапку «Properties» и настройки видимости/порядка. Начать с группы «Названия», затем «Ботанические сведения»; все актуальные поля показываются в постоянном порядке. Возможность сворачивать группы сохраняется, как и управление видимостью всей правой панели через верхнюю кнопку Explorer.

## Grid, Table, Search (согласованы к внедрению)

Grid: имя модели + при наличии название по-русски и по-английски тонким вторичным шрифтом; под карточкой Vol не показывать. Table: имя, русское, английское, латинское, цветение, группа/категория растения, тип/категория среды. Для нескольких сред отобразить все значения. Search: filename, RU/EN/Latin, имена связанных похожих растений по similar_json, частичные совпадения без регистра.

## Границы

FloraAtlas v1 - SQLite, ботанические поля `plants` и `models` по `relative_path`; `landscaped_json` показывается как «Домашние». Тематический формат FloraCOL сохраняется. Не использовать старый FloraCat, старые категории, Scatter, пакетную автоматическую генерацию превью или прежний анализ геометрии. HTML - только демо, реальные импорты и свойства работают в PySide6/3ds Max.
