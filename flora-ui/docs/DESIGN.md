# Правила дизайна Flora UI

Основой служит фактический интерфейс **Flora 1.0**, который пользователь показал скриншотами 14 октября 2026. Не проводить редизайн без согласования.

## Визуальный язык

- Тёмные зелёно-серые поверхности; основа \`#111c15\`, панели \`#17241b\` и \`#1c2d21\`.
- Акцент - приглушённый природный зелёный; активные элементы \`#315d3a\`, текст акцента \`#a6db7e\`.
- Тонкие границы \`#2f4b37\`, мягкие скругления 5–9 px, отсутствие объёмных декоративных эффектов.
- Шрифт - \`Inter\`, затем системный \`Segoe UI\`. Отступы небольшие и одинаковые.
- Сетка растений изменяет число колонок вместе с шириной окна. Превью не растягиваются неравномерно.
- Один выделенный режим на группу переключателей. Выбор растения подсвечивает карточку без отдельного чекбокса.
- Настоящие внешние окна - отдельные страницы/окна, а не полная подмена основного каталога.

## Иерархия

1. Шапка Flora с рабочими режимами, Library, Refresh, Material Manager, Settings.
2. В Catalog - Explorer, Favorites, Basket и установленные каталоги `.floracat`. Landscape - пример подключённого каталога, не неизменяемая часть ядра.
3. Левая колонка с деревом папок/категорий/коллекций.
4. Центральная область с названием, строкой поиска, сортировкой и Grid/List.
5. Сетка карточек или компактный список, справа Property / Value. У карточек доступна небольшая иконка добавления в Basket при наведении; выбор и Drag & Drop сохраняются.
6. Нижняя панель выбора Corona Proxy Geometry / Point Cloud.

Basket - полноценная вкладка того же Catalog. Карточки имеют отдельные чекбоксы включения в импорт, удаление, компактный ползунок размера, Clear Basket и Import. При изменении размеров окна сетка адаптируется. Никаких дополнительных окон для самой корзины, расстановки по поверхности, сеток или контейнеров.

Explorer получает отдельную кнопку Import Plant Data для файлов описаний `.floracat`; Add Catalog по-прежнему подключает самостоятельный тематический каталог. Данные Explorer не должны создавать вкладку.

Material Manager сохраняет отдельные вкладки Relink, Textures, Materials. Общий \`Processing Scope\` показывается только в Textures и Materials, а не в Relink.


## Обслуживание

Главные стили находятся в \`styles.css\`; интерактивность и тестовые модели - в \`app.js\`. Материал-менеджер в отдельном \`material-manager.html\` пока сохраняет встроенные CSS/JS из уже утверждённого макета для независимого открытия.

Не переносить в этот репозиторий рабочие \`.max\`, \`.cgeo\`, закрытые библиотеки растений или пользовательские данные.
