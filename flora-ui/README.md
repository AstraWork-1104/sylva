# Flora UI V2 - утверждённый дизайн

Ветка: `flora-ui-v2`. Папка: `flora-ui/`.

Открыть [архив ветки](https://github.com/AstraWork-1104/sylva/archive/refs/heads/flora-ui-v2.zip), распаковать и открыть `flora-ui/Flora-UI.html` в браузере. Модульные исходники: `index.html`, `styles.css`, `app.js`, `material-manager.html`, `model-analyzer.html`.

## Статус реализации

Это браузерный визуальный референс, не код плагина 3ds Max. Зависимые Filters уже согласованы и отражены в прототипе. Поздние изменения Properties, подписей карточек, List/Table, поисковых полей и Settings также согласованы, но до их внедрения могут не совпадать с макетом. В случае расхождения последнее решение пользователя и актуальное описание Flora имеют приоритет.

## Требования к Filters

- Группа: Все группы, Деревья, Кусты, Трава; категория недоступна без конкретной группы, при выборе показывает только её допустимые категории.
- Деревья: Лиственные, Хвойные, Пальмы. Кусты: Лиственные, Хвойные, Папоротники, Злаки, Вьющиеся, Многолетники, Суккуленты. Трава: Травы, Цветы, Почвопокровные, Луковичные.
- Тип среды: Все среды, Природные, Домашние; категория среды недоступна без конкретного типа.
- Природные: Лесная, Луговая, Водная, Прибрежная, Степная, Пустынная, Горная. Домашние: Улицы, Парки, Сады, Дворы, Интерьеры.
- Цветение: Все, Да, Нет. Высота, см: отключённые От/До до будущих замеров.
- Смена родителя сбрасывает категорию; компактное адаптивное размещение слева; независимая прокрутка Filters по высоте.

## Последние согласованные UI-правки для реализации

Properties начинается сразу с раскрываемых «Названия» и «Ботанические сведения»; никакой внутренней шапки, шестерёнки, настраиваемого порядка/видимости полей. Карточки: основное имя модели, ниже при наличии name_ru и name_en вторичным шрифтом, без номера Vol. Table: имя, RU/EN/Latin, цветение, группа, категория, тип и категория среды; устаревшие поля удалить. Поиск по filename, RU, EN, Latin и названиям похожих растений из `similar_json`. Settings: удалить поддержку .floracat, добавить безопасную очистку импортированных данных, не удаляя избранное, коллекции и локальные файлы.

Технический формат FloraAtlas v1 не меняется; на UI «Домашние» соответствует `landscaped_json`, «Природные» - `natural_json`; оба массива могут содержать несколько категорий одновременно. Тематический FloraCOL сохраняется.

Дизайн - плоский тёмно-зелёный без рельефа. Автономный HTML нужно синхронизировать с модульными CSS/JS. См. `docs/DESIGN.md` и `docs/SCREENS.md`.
