# Flora UI - актуальный макет

Единственный действующий интерактивный дизайн интерфейса **Flora** для 3ds Max 2026 и Corona Renderer 14.

**Дизайн: первоначальный, с плоскими кнопками.** Эффекты из экспериментальных объёмных вариантов не используются. Категорически не переносить в макет старые blocks CSS `tactile depth`, `satin finish`, сильные тени, скосы и глянцевые кнопки.

## Открыть интерфейс

1. В GitHub выберите ветку **`flora-ui`**.
2. Нажмите **Code → Download ZIP**, распакуйте архив.
3. Откройте **`flora-ui/Flora-UI.html`** в браузере.

Этот HTML полностью автономен. В нём находятся основной Catalog, Explorer, Favorites, Import Basket, подключаемые каталоги и окно Material Manager с вкладками Relink, Textures, Materials. Содержимое является **интерактивным прототипом**, а не исполняемым кодом для изменения сцены 3ds Max.

GitHub Blob и Raw показывают исходный HTML или скачивают его, но не запускают визуальный интерфейс в браузере GitHub.

## Единственная рабочая структура

```text
flora-ui/
├── Flora-UI.html             - автономный просмотр, тот же дизайн
├── index.html                - HTML основного окна, исходник
├── styles.css                - единственные исходные стили, плоские кнопки
├── app.js                    - логика интерактивного браузерного макета
├── material-manager.html     - исходник отдельного окна Material Manager
├── README.md                 - навигация
└── docs/
    ├── DESIGN.md             - утверждённые визуальные правила
    └── SCREENS.md            - список экранов и статусы функций
```

`Flora-UI.html` не отдельная альтернативная версия: это самостоятельная сборка из текущих исходников. Стили внутри него должны всегда совпадать с `styles.css`, а встроенные JavaScript-модули должны проходить проверку синтаксиса.

## Что входит

- Catalog: Explorer, Favorites, Basket и установленные .floracat (Landscape только пример внешнего каталога); Grid/List, поиск, сортировка, выбор растений и панель свойств.
- Import Basket: модель добавляется иконкой на карточке, через контекстное меню или Shift + правый клик; поддерживаются групповое выделение, локальное сохранение списка, включение чекбоксом, изменение размера плиток, удаление, Clear Basket и окно Import Preview. Реальный Merge не выполняется.
- Explorer Plant Data: отдельная кнопка Import Plant Data. В браузере имена выбранных информационных .floracat сохраняются локально, но содержимое SQLite не считывается и метаданные моделей не изменяются. Это не то же самое, что Add Catalog.
- Material Manager: независимые Relink, Textures, Materials.
- Settings: в том числе Use Scene Materials.

Корзина в действующем плагине должна импортировать выбранные модели в (0, 0, 0), сохраняя имена и помещая всё в один слой Flora Import через общий механизм Merge / Corona Proxy; конфликты имён объектов проверяются по всей сцене, а Use Scene Materials применяется из общих Settings. **В HTML этот импорт не выполняется:** кнопка Import открывает только предварительный просмотр и не очищает корзину.

Данные растений и результаты операций в браузере - демонстрационные. Никакие действия макета не меняют файлы библиотек и сцену Max.

## Правило для следующих задач и Codex

Используйте **только текущую ветку `flora-ui`** и описанные выше исходники. Не восстанавливайте стили из истории Git, архивных веток или чужих HTML-прототипов. Визуальный эталон: **первоначальные плоские кнопки Flora**. В конце любой задачи по UI синхронизируйте `Flora-UI.html` с исходниками, проверьте синтаксис встроенного JavaScript и сравните CSS. Ссылка на этот каталог остаётся неизменной.

Подробнее: [DESIGN.md](./docs/DESIGN.md) и [SCREENS.md](./docs/SCREENS.md).
