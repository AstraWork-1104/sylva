# Flora UI

**Рабочий интерактивный макет интерфейса Flora**  
3ds Max 2026 · Corona Renderer 14 · дизайн и UX-прототип

Это постоянная рабочая версия макета. Она не является кодом плагина, не обращается к локальным файлам пользователя и не выполняет операции над сценой 3ds Max.

## Как открыть интерфейс

1. Откройте [index.html](./index.html) в репозитории.
2. Нажмите **Raw / Download raw file** и сохраните файл вместе с файлами \`styles.css\` и \`app.js\` из этой папки.
3. Откройте \`index.html\` в Chrome, Edge или Firefox. Внешних библиотек или сборки не требуется.

Для удобства лучше скачать всю ветку репозитория ZIP-архивом, распаковать и открыть \`flora-ui/index.html\`. Тогда все внутренние ссылки и стили останутся на месте.

**Material Manager** открывается кнопкой с иконкой слоёв справа в верхней панели Flora и находится в отдельном файле \`material-manager.html\`.

> GitHub в режиме Blob показывает HTML как код. Живой браузерный просмотр через GitHub Pages пока не настроен: исходный репозиторий приватный. Это не ограничение макета - HTML полностью работает локально после скачивания.

## Основные экраны

- **Catalog → Explorer** - дерево папок MaxTree, поиск, сортировка, Grid/List, выделение, свойства моделей, Favorites, режим Corona Proxy.
- **Catalog → ★ Favorites** - сохранённые модели, коллекции, поиск и сортировка.
- **Catalog → Landscape** - пример внешнего \`.floracat\` с категориями и свойствами. \`Add Catalog\` демонстрирует добавление вкладки, но не разбирает SQLite.
- **Material Manager** - отдельное окно с Relink, Textures и Materials, собственными элементами управления и результатами-примерами.
- **Settings** - предусмотренный параметр \`Use Scene Materials\`, включённый по умолчанию; переключение политики Merge отображается концептуально.
- **Scatter → Spring / Grove / Biome** - будущие режимы распределения, интерактивные элементы и визуальный пример рассадки, явно обозначенные **CONCEPT**.

## Источник требований

Основой служат утверждённые скриншоты работающей Flora и документ «Flora - Описание концепции плагина» (обновлён 14 октября 2026). Scatter - три независимых режима Spring, Grove, Biome.

## Правила работы с этим репозиторием

- Все дальнейшие визуальные изменения интерфейса вносятся именно в **\`flora-ui/\`** ветки **\`flora-ui\`**.
- Дизайн хранится отдельно от исходников 3ds Max, не создаёт файлов \`.max\`, \`.cgeo\` или \`.floracat\`.
- Тестовые прототипы старой ветки \`flora-ui-connection-test-20261014\` сохраняются только как история эксперимента.
- Изображения растений в этом браузерном макете - процедурные иллюстративные SVG-превью, не оригинальные JPG из MaxTree. Реальная Flora использует изображения файловых библиотек.
- Взаимодействия имитируют работу будущего интерфейса. Они не выполняют файловый relink, материал-merge, scatter, Proxy конвертацию или импорт моделей.
- При изменении интерфейса сохраняем утверждённую тёмно-зелёную стилистику и работу окна при изменении размеров.

См. [SCREENS.md](./docs/SCREENS.md) для границы между действующим продуктом и запланированными функциями.
