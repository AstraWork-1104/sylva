# Flora UI - Graphite Studio

[Открыть новый серый макет](https://astrawork-1104.github.io/sylva/flora-ui-max/)

Вторая независимая версия Flora оформлена в стиле Graphite Studio: глубокие графитовые поверхности, матовые карточки, более выразительная иерархия серого и светлые платиновые акценты. Вместо насыщенной зелёной подсветки активные элементы имеют тонкие серебристые рамки. Только точка присутствия модели в сцене остаётся зелёной.

Исходники `source.html`, `styles.css`, `app.js`; автономные `index.html` и `Flora-UI.html` синхронизируются. Функции, 36 демомоделей и настройки `flora-ui-warm-v1` сохранены. Исходная зелёная Flora в `../flora-ui/` не изменяется.
