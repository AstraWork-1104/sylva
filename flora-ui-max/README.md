# Flora UI - 3ds Max Dark

**[Открыть обновлённый макет](https://astrawork-1104.github.io/sylva/flora-ui-max/)**

Это второй самостоятельный макет Flora в цветовой схеме тёмного Autodesk 3ds Max. URL отличается от прежнего Warm Gray, чтобы исключить загрузку старого HTML и CSS из кэша.

Визуальное решение: многоуровневые графитовые панели (например, `#383838`, `#454545`), нейтрально-серые поля и кнопки, приглушённые стально-синие активные состояния, янтарная рамка выбранной модели. Зелёная точка присутствия модели в сцене остаётся зелёной по смыслу. Это визуальная имитация оформления 3ds Max, не официальный файл схемы Autodesk.

**Структура:** `index.html` и `Flora-UI.html` - одинаковые самодостаточные документы со встроенным CSS и JavaScript, не требующие загрузки отдельных ресурсов при открытии на GitHub Pages. `source.html`, `styles.css`, `app.js`, `material-manager.html`, `model-analyzer.html` - редактируемые модульные исходники. Изменения в исходниках нужно синхронизировать с обеими автономными страницами.

Пока новый вариант использует существующее браузерное хранилище второго макета `flora-ui-warm-v1`, поэтому сохранённые Favorites, Basket и настройки остаются доступны. Исходная зелёная Flora находится в `../flora-ui/` и не изменена. Функции и 36 тестовых моделей сохранены.

Это только HTML-демонстрация без реальных команд для 3ds Max, Corona, файлов .max или SQLite. Общая [карта функций UI](../flora-ui/docs/UI_MAP.md).
