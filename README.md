# Flora UI V2 - утверждённый визуальный референс

**Единственный актуальный визуальный референс для следующего обновления плагина Flora:** [flora-ui-v2/flora-ui](https://github.com/AstraWork-1104/sylva/tree/flora-ui-v2/flora-ui).

Скачать [ZIP текущего дизайна](https://github.com/AstraWork-1104/sylva/archive/refs/heads/flora-ui-v2.zip), открыть после распаковки `flora-ui/Flora-UI.html`. Редактируемые модули: `flora-ui/index.html`, `flora-ui/styles.css`, `flora-ui/app.js`. Автономный HTML собирается из тех же источников.

**Статус:** утверждённые Filters уже представлены в браузерном UI V2. Остальные поздние изменения (шапка Properties, подписи карточек, Table View, поиск, очистка метаданных) согласованы для рабочего PySide6-плагина и могут ещё отсутствовать в макете. Не трактовать демонстрационный HTML как функционирующий Python/3ds Max-код.

Формат ботанических каталогов - SQLite `.floratlas` v1, тематические каталоги - `.floracol`. Старый ботанический `.floracat` отменён.

Главное описание функционала: [Flora - Описание плагина](https://docs.google.com/document/d/19MQLTbmyikvPj2wCLwIvuSqF3sdwJ8YUlSEtsMSkbZ0/edit).
