# Flora - версии дизайна

**Утверждённый исходный макет:** ветка flora-ui, папка flora-ui/. Он не изменён.

**Новая версия на проверку:** ветка flora-ui-v2, папка flora-ui/. Это отдельный интерактивный дизайн, не код плагина 3ds Max.

Для просмотра скачайте ZIP нужной ветки, распакуйте и откройте файл flora-ui/Flora-UI.html в браузере. Material Manager и Model Analyzer открываются отдельными окнами.

Новая версия V2 не заменяет исходный утверждённый вариант до проверки пользователем.
