# KitchenBuilder

Отдельная папка проекта KitchenBuilder в репозитории.

Плагин для процедурного создания кухонь в Autodesk 3ds Max 2024+ с использованием Corona Renderer.

Рабочие файлы KitchenBuilder размещаются только внутри этой папки. Существующий проект Flora и остальные файлы репозитория не относятся к KitchenBuilder.

Исходный код и материалы будут добавляться по отдельным задачам.
